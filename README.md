# Partners for Construction website

Static website for **Partners for Construction** (formerly Demas for Construction and Blue for Construction & Supplies): aqua parks, water slides, swimming pools, water fountains, kids play areas, sports surfaces, shades and site furniture.

- Pure HTML/CSS/JS, no build step. Open `index.html` or serve the folder.
- Project portfolio data lives in `assets/projects.js` (category, title, location, photos). Add a project by appending an entry and dropping its photos into `assets/projects/`.
